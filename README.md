# UV-Vis Spectrophotometer – Levitator-Based Concept (SolidWorks)

A custom-designed concept for a UV-Vis spectrophotometer that uses acoustic
levitation to hold the sample. I modeled every part and built the full
assembly myself in SolidWorks.

## Highlights
- Full assembly: monochromator, light source, power supply, sample drawer
- Designed as part of a startup initiative; the idea was later acquired
  by an external vendor
- Tools: SolidWorks (modeling, assembly, rendering)
